# คู่มือผู้ใช้งาน / User Manual

## เข้าสู่ระบบ / Sign in
ไปที่ `/login` — ใช้อีเมล+รหัสผ่าน หรือ "เข้าสู่ระบบด้วย Google"
หากบัญชีเปิด MFA ระบบจะถามรหัส 6 หลักจากแอป Authenticator
ล็อกอินผิด 5 ครั้ง บัญชีถูกล็อก 15 นาที

## แดชบอร์ด / Dashboard
สรุปทรัพย์สินตามสถานะ, ไลเซนส์/ประกัน/บริการใกล้หมดอายุ, งานซ่อมค้าง,
รายการรออนุมัติ, กิจกรรมล่าสุด และการแจ้งเตือนความปลอดภัย
กรองตามแผนก/สถานที่/หมวดหมู่ได้จากด้านบน

## ทรัพย์สิน / Assets
- ค้นหา/กรองรายการ → คลิกดูรายละเอียด ประวัติ การมอบหมาย งานซ่อม และ
  Credential ที่เชื่อมโยง (เห็นเฉพาะชื่อ ไม่เห็นรหัสผ่าน)
- **QR Code**: ทุกทรัพย์สินมี QR — พิมพ์สติกเกอร์จากปุ่ม "พิมพ์สติกเกอร์"
  สแกนด้วยกล้องมือถือจะเปิดหน้า `/scan/{id}` แสดงข้อมูลสรุป
- **เบิก (Check-out)**: Assets → Assign เลือกทรัพย์สิน+พนักงาน กำหนดวันคืน
- **คืน (Check-in)**: Assets → Return บันทึกสภาพและความเสียหาย
- **โอนย้าย**: Assets → Transfer เปลี่ยนแผนก/สถานที่/ผู้ถือครอง

## ตู้เซฟรหัสผ่าน / Password Vault
- "เพิ่มรหัสผ่าน" — มีตัวสร้างรหัสผ่าน (คลิกไอคอนไม้กายสิทธิ์) พร้อมมาตรวัด
  ความแข็งแรง รหัสถูกสร้างในเบราว์เซอร์
- **เปิดเผย (Reveal)**: กดปุ่ม Reveal — ระดับ HIGH/CRITICAL ต้องยืนยัน +
  กรอกรหัส MFA ระบบซ่อนอัตโนมัติใน 30 วินาที ทุกครั้งถูกบันทึก Audit
- **คัดลอก (Copy)**: คัดลอกไปคลิปบอร์ด ระบบพยายามล้างคลิปบอร์ดใน 30 วินาที
- **แชร์**: เจ้าของแชร์ให้ผู้ใช้/บทบาท/แผนก เลือกระดับสิทธิ์และวันหมดอายุ
  (1 ชม.–30 วัน) สิทธิ์ถูกเพิกถอนอัตโนมัติเมื่อหมดเวลา
- **ฉุกเฉิน (Break glass)**: หากรายการต้องขออนุมัติ ส่งคำขอพร้อมเหตุผล
  ที่หน้า Vault → Emergency ผู้จัดการไอทีเป็นผู้อนุมัติพร้อมกำหนดเวลา
- **รอบเปลี่ยนรหัส**: หน้า Rotation แสดงรายการที่ถึงกำหนด กด Manage เพื่อ
  บันทึกการเปลี่ยน (Rotated/Verified/Skipped)

## แจ้งซ่อม / Maintenance
สร้าง Ticket เลือกทรัพย์สิน ระบุปัญหาและความเร่งด่วน — สถานะเครื่องจะเป็น
"ซ่อม" อัตโนมัติ และกลับเป็น "พร้อมใช้" เมื่อปิดงาน

## จัดซื้อ / Procurement
สร้างใบขอซื้อ (สูงสุด 5 รายการ) → อนุมัติ 3 ขั้น: Manager → IT → Finance →
สั่งซื้อ → รับของ → ลงทะเบียนเป็นทรัพย์สิน

## โปรไฟล์ / Profile (Settings → Profile & Security)
เปลี่ยนรหัสผ่าน, เปิดใช้ MFA (สแกน QR + ยืนยันรหัส 6 หลัก),
ดู/เพิกถอน Session ทุกอุปกรณ์, เปลี่ยนภาษา ไทย/English
ปุ่มสลับธีมมืด/สว่างและภาษาอยู่มุมขวาบน
